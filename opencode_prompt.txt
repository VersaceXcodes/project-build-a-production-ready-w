Add an admin-controlled setting to hide/show all Products features from the public website.

1) System Settings toggle (admin only)

Create a toggle in Admin → System Settings:

Label: Enable Products (Public)

Key: productsPublicEnabled (boolean)

Default: false (Products hidden by default)

Only admins can change this setting. Save it in the database.

2) When productsPublicEnabled = false (Products OFF)

Hide or disable everything related to Products on the public site:

Navigation / UI

Remove the Products tab from the top navbar (desktop + mobile).

Remove any Products links from footer, menus, CTA buttons, or homepage sections.

Homepage

Completely hide the “Best Sellers — Our Most Ordered Print Products” section (no rendering and no empty spacing).

Do not fetch product data for the homepage when Products are OFF.

Pages / Routes

Block public access to any product pages:

/products

/products/[slug] (or any product detail route)

any category pages or product-related routes
Return 404 or redirect to /.

API / Data

Block public product APIs when Products are OFF (return 404/403 or empty response).

Admin endpoints (e.g. /admin/products) must still work normally.

Search / Sitemap

Remove product pages from sitemap / internal search results (if implemented).

3) When productsPublicEnabled = true (Products ON)

Show Products tab and all product pages normally.

Show Best Sellers section on the homepage normally (and fetch data).

Acceptance criteria

Turning Products OFF removes Products from navbar + homepage + all public routes/APIs.

Admin can still manage products in the admin panel.

Turning Products ON restores everything.
